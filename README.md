# Shiv Akash S M — Portfolio

Personal portfolio site. Content lives in `src/data/content.ts`.

## Stack

React · Vite · TypeScript · Tailwind CSS · React Router · Framer Motion

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content & assets

| Path | Purpose |
|------|---------|
| `src/data/content.ts` | All copy, projects, experience, skills |
| `public/photo.svg` (or `.jpg`) | Profile photo — replace with your headshot |
| `public/Shiv_Akash_S_M_Resume.pdf` | Resume PDF |
| `public/certs/*` | Certificate / experience-letter images |

To add a project: copy the placeholder entry in `content.ts`, fill fields, set `published: true`.

## Shortcuts

- `⌘/Ctrl + K` — command palette
- `G` then `H` / `W` / `A` / `C` — navigate
- `?` — shortcuts dialog
